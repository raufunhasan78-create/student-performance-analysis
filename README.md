# 📊 Student Performance EDA Project

## 📝 Project Overview
This project performs Exploratory Data Analysis (EDA) on a Student Performance dataset. The goal is to analyze how different factors like study hours, attendance, and gender impact students' exam scores. 

## 🛠️ Tools & Libraries Used
* *Python*: Primary programming language
* *Pandas*: Data manipulation and cleaning
* *Matplotlib & Seaborn*: Data visualization

## 📈 Key Insights Found
1. *Study Hours vs Score*: Students who invest more time in studying tend to achieve significantly higher exam scores.
2. *Attendance vs Score*: Higher class attendance strongly correlates with better academic performance.
3. *Gender Analysis*: Exam score distributions were compared across genders using boxplots to observe performance trends.
